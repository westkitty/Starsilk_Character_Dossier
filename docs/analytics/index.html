    About these numbers

    All figures are deterministic sample data generated from src/analytics/dashboard.json (seed 20260909) by build/analytics_publication.py. They illustrate dashboard behavior only and must never be quoted as real readership, canon, or publication evidence.

    Aggregation is view-only: range sums, per-day trend deltas, segment affinity weighting, and table sorting change the rendered view without altering the published analytics.json. The page sets no tracking cookies and stores only a browser-local theme preference.
