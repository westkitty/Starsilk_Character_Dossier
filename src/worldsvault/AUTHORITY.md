# WorldsVault cosmic topology authority boundary

`src/worldsvault/topology.json` is a Phase 10 index of only direct topology statements recoverable from the cited existing Compendium sections. The cited section bodies remain the authority for prose. The index and all `docs/worldsvault/` files are deterministic public derivatives, not a second canon database.

## Identity, evidence, and scope

Existing top-level stable IDs are reused where one exists. Other node and edge IDs are deterministic **publication IDs** derived from an exact source-backed display label and are marked `publication-derived`; they are not newly authored permanent identities. Source labels, headings, paths, and existing canonical/legacy locations remain attached to every node and edge.

An edge is emitted only where the cited text directly states its relation. The existing 136 `mentions` / `observed-xref` edges remain unchanged and are not promoted, copied, or reclassified as topology evidence.

## Spatial and status limits

No authored coordinates, distances, directions, route geometry, membership, system extent, or complete cosmographic map exists in the current source. `layout` stores only deterministic rendering group/order and is explicitly non-canonical; it is not a position claim and is never exported as cosmic location data.

The cited source records are public. Per-node and per-edge canon status and spoiler level are not authored, so both remain `unknown`. Public visibility is not a canon assertion.
